# todo-cli revival
python搭建一个命令行待办工具（todo CLI）

# 目的

掌握：
python项目基本组织 
    -导入所用模块库
    -构建函数（用什么参数传什么参数），考虑情况全面
    -main()函数放主要业务逻辑
命令行参数（argparse）
    -构建解析器（主解析器和子解析器）
    -子命令添加并配置参数
JSON文件读写做持久化
    -用到json.load()json.loads();json.dump()json.dumps()注意区别
    -通过临时文件来避免写入保存出错，tempfile模块对应着os模块

回顾：
函数、列表/字典  
文件IO与异常处理 try except 
程序退出码
